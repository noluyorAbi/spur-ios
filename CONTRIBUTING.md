# Contributing

Spur's source is published to be read, and it is not licensed for reuse (see `LICENSE`).
Issues are welcome: bug reports, questions about how something works, and ideas. Pull requests
are not accepted, because every contribution would have to come with a copyright assignment.

When you report a bug, say which version (Einstellungen shows it), what you did, and what you
expected. A GPX or JSON export of the trip helps most; check it for places you do not want to
share before attaching it.
